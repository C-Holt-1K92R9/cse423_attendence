Admin Manual

Overview

This web application is designed to manage and track attendance efficiently. As an admin, you have access to all features required to set up, monitor, and report attendance data. Recent updates have introduced new features to enhance usability and reporting.

How the Web App Works

  • Login: Admins log in using their credentials to access the dashboard.
  • User Management: Add, edit, or remove users (students, teachers, or staff) from the system.
  • Bulk User Import: Upload user lists via CSV for faster onboarding.
  • Attendance Sessions: Create and schedule attendance sessions for different classes or events.
  • Recurring Sessions: Set up sessions to repeat automatically on selected days.
  • Mark Attendance: Users can mark their attendance through the web interface or QR code scanning (if enabled).
  • Manual Attendance Adjustment: Admins can manually update or correct attendance records.
  • View Reports: Generate and export attendance reports for specific dates, users, or sessions.
  • Advanced Filtering: Filter reports by class, date range, or attendance status.
  • Notifications: Send notifications or reminders to users about attendance requirements.
  • Automated Reminders: Schedule automatic reminders for upcoming sessions.

Best Practices

  • Regularly update user information to keep records accurate.
  • Use the bulk import feature for efficient user management.
  • Monitor attendance reports and use filters to identify irregularities.
  • Backup data periodically to prevent loss.
  • Review audit logs to ensure proper use of admin privileges.
  • Ensure only authorized personnel have admin access.

For further assistance, contact the system administrator.
