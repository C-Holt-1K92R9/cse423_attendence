Admin Manual

Overview

This web application is designed to manage and track attendance efficiently. As an admin, you have access to all features required to set up, monitor, and report attendance data.

How the Web App Works

  • Login: Admins log in using their credentials to access the dashboard.
  • User Management: Add, edit, or remove users (students, teachers, or staff) from the system.
  • Attendance Sessions: Create and schedule attendance sessions for different classes or events.
  • Mark Attendance: Users can mark their attendance through the web interface or QR code scanning (if enabled).
  • View Reports: Generate and export attendance reports for specific dates, users, or sessions.
  • Notifications: Send notifications or reminders to users about attendance requirements.
  • Settings: Configure system settings such as session timings, notification preferences, and more.

Best Practices

  • Regularly update user information to keep records accurate.
  • Monitor attendance reports to identify irregularities.
  • Backup data periodically to prevent loss.
  • Ensure only authorized personnel have admin access.

For further assistance, contact the system administrator.
