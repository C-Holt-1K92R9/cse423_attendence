Admin Manual

Overview

This web application is designed to manage and track attendance efficiently. As an admin, you have access to all features required to set up, monitor, and report attendance data. Recent updates have introduced new features to enhance usability and reporting.

How the Web App Works

  • Take Attendance: When the "Start Attendance" button is pressed, a new column is created in the database for that day. Simultaneously, a QR code containing a verification token is generated. Students must scan this QR code to mark their attendance. Once the QR code is closed, no further attendance submissions will be accepted for that session.

  • Manual Attendance Present: Faculty member can manually mark attendance for students who are unable to scan the QR code but are present in the class. This is done by entering the student's ID and clicking "Mark Attendance". The system will validate the ID and update the attendance record accordingly.

  • Manual Attendanceb Absent: While marking a students attendece, if a wrong StudentID is enter (for another student, who is not present), it can be undone using the the mark abset attendance card.

  • Add Student: Faculty members can add students to the database individually or in bulk by uploading a CSV file.
    Note: The CSV file must follow this format: student_id, name, email, course_code, section.

  • Reports: Faculty members can download attendance history by section as a CSV file. Select the desired section and click "Generate Report" to obtain the data.

Best Practices

  • Use the bulk import feature for efficient user management.
  • Monitor attendance reports and use filters to identify irregularities. [Comming soon....]
  • Backup data periodically by downloading the reports for each section to prevent any loss.
  • Ensure only authorized personnel have admin access.
